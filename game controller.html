What the values mean
Gamepad axes Sticks normally report from -1.00 to +1.00. Near 0 means centered. BuildView multiplies these values by movement or look speed.
Gamepad buttons Each button has an index such as B0 or B9 and usually a value from 0 to 1. Triggers may report gradual values.
Mouse / keyboard mode If Android converts the controller into pointer, arrow-key, or wheel events, BuildView must listen to that input path instead of only navigator.getGamepads().
